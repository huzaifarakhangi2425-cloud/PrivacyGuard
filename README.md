# PrivacyGuard demo

A free personal privacy dashboard, hosted on GitHub Pages.

## What it does

Answer a short privacy self-assessment, build a practical action plan, track your checklist, and download a text copy. Progress is saved in this browser's local storage. Use Clear my data to remove it.

This demo provides educational guidance. It does not scan devices, monitor accounts, block trackers, or provide a VPN.

## Hosting

Serve the repository root as a static site. GitHub Pages should publish from the `main` branch and `/(root)` folder. All asset links are relative, so the demo works under `/PrivacyGuard/`.

The separate paid membership app requires server-side sign-in, a database, and payment verification; those services are not part of this static demo.
